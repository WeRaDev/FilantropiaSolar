## Dataset Information

The Photovoltaic Power Production Dataset includes:

- **Coverage**: 9+ photovoltaic installations across Portugal
- **Time Period**: Multiple years of historical data
- **Resolution**: Hourly measurements
- **Parameters**: Energy production, specific energy (kWh/kWp), weather data
- **Format**: CSV files processed from original Excel sheets
- **Total Records**: 315,567+ historical energy production records

## Usage Guidelines

1. **Always cite the original dataset** when publishing research or analysis using this data
2. The data files in this project are CSV files created specifically for this study from the original Excel sheets
3. Any modifications or derived works should acknowledge both the original dataset and any transformations applied
4. For commercial use, please review the dataset license terms on Mendeley Data
